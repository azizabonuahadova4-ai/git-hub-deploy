## 📖 Loyiha haqida

> *"Kelajakni biz bilan quring!"*

Bu loyiha **HTML va CSS** yordamida alohida yozilgan, zamonaviy va **mobil qurilmalarga to'liq moslashuvchan** veb-sahifadir. Toza kod strukturasi va foydalanuvchilarga qulay dizayn asosida qurilgan.

---

## ✨ Xususiyatlari

- 📱 **Responsive dizayn** — barcha qurilmalarda chiroyli ko'rinadi
- 🎨 **Zamonaviy UI** — toza va foydalanuvchiga qulay interfeys
- ⚡ **Tez yuklanish** — optimallashtirilgan HTML & CSS kod
- 🔗 **Navigatsiya** — Bosh sahifa, Xizmatlar, Aloqa bo'limlari
